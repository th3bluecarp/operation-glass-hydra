# Objectives

Determine, with evidence:
1. Initial access vector
2. First confirmed user or host compromise
3. Whether MFA was bypassed or satisfied
4. How persistence was established
5. Primary lateral movement path
6. What data was staged or accessed
7. Whether ransomware was real, partial, or decoy
8. Which cloud actions were attacker-driven
9. Which indicators are red herrings
10. Exact containment priorities
